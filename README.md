# 🎾 Tennis Club Social Media Manager

Aplicación web frontend para organizar y planificar la gestión de redes sociales de un club de tenis.

## ✨ Funcionalidades
- Organización de publicaciones por red social
- Gestión de ideas de contenido
- Registro de fotos y videos
- Planificación de fechas y eventos del club

## 🛠️ Tecnologías
- HTML5
- CSS3
- JavaScript
